# Windows 鄰鍵容錯測試包

[下載 ZIP](./0c-windows-neighbor-preview-1.zip?raw=true)（約 17 MB）

版本 **0.2.8-preview.neighbor.1**。適用已安裝正式版 **0.2.7** 或上一個 **0.2.8-preview.mixedpolicy.1** 的 Windows x64，同一個 Windows 帳號。不能全新安裝，不適用 ARM64。
沿用已校驗的 TSF、UI、設定程式、字典及模型，換上含鄰鍵容錯的引擎和更新工具，保留個人詞庫與既有混打偏好。

1. 完整解壓 ZIP。
2. 儲存工作，以原安裝帳號右鍵 `0c-neighbor-test-setup.exe` → 以系統管理員身分執行。
3. 安裝完成後登出 Windows 再登入。
4. 保持中英混打開啟，雙擊 `Neighbor-On.cmd`，會切到積極混打並開鄰鍵容錯。

`Neighbor-Off.cmd` 只關掉鄰鍵容錯，方便比較。切換不需要管理員；請先完成目前組字。
若仍用內建輸入習慣，須先複製成自訂，才能打開混打。沿用的舊設定 UI 可能把新開關列在「選字」頁。

先比較 `ki3`（j 誤按成 k）：開啟應恢復為「我」；`helloki3cl3` 應為「hello我好」。
`qji3` 有多個可能讀音，會留原鍵，按 ↓ 看鄰鍵候選，Enter 不暗中接受候選。

第一版僅 QWERTY、標準注音、積極混打、有明確聲調，且只在完整讀音失敗時替換一個鄰鍵。
不改聲調、不修純數字、不改原本能組字的讀音。多鍵誤按、其他注音排列不在本版範圍。
自動修正可從候選選回原按鍵，未經手選確認不進個人學習。積極混打原有帳號／型號取捨仍在，需要英數原文時切英文模式。

要固定測試版，可雙擊 `Manual-Updates.cmd`；`Auto-Updates.cmd` 恢復自動更新。
同帳號以管理員執行 `Rollback.cmd` 可回復安裝前的版本，保留目前個人詞庫；完成後登出再登入。
更新偏好保留至回復後，需要恢復自動更新時再用 Auto-Updates.cmd。

這是未簽章測試包。核心與設定回歸、正式字典、隔離 IPC、兩種基底的套件準備及校驗、Windows x64 交叉編譯均通過；Windows 原生安裝／回復、候選視窗及 TSF 密碼欄位仍待實測。
完整說明、校驗、設計、授權和原始碼隨 ZIP 提供。
