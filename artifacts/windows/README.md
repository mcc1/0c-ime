# Windows 混打功能測試包 — 0.2.11-preview.mixed.1

本次基於上游公開 `release/0.2.10` 原始碼，合併積極／保守混打、鄰鍵容錯與設定頁子選項。
需要先安裝正式版 Windows x64 **0.2.10**；本包是升級測試工具，不能全新安裝。

保守模式保留上游帳號邊界；積極模式允許數字誤按後恢復中文。積極模式仍可能轉換帳號／型號。
不含尚未完成品質實驗的 Shift 回切排名器。

安裝與驗證紀錄隨建置產物一併更新。未簽章，尚未在 Windows 實機驗證。
